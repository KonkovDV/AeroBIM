# Hybrid AI — политика маршрутизации (fail-closed)

Companion к `HYBRID_AI_ARCHITECTURE_2026_07_28.md`. Определяет class×route матрицу,
входы policy engine и поведение при неопределённости. **SSOT кода — Wave 2**
(`domain/hybrid/trust_policy.py`); этот документ — спецификация.

## 1. Матрица класс × маршрут (по умолчанию)

| Класс | LOCAL | PRIVATE (закрытый контур) | PUBLIC (внешний API) |
|---|---|---|---|
| PUBLIC | разрешено | разрешено | разрешено |
| INTERNAL | разрешено | разрешено после политики | только после явного согласия |
| CONFIDENTIAL | разрешено | только при подтверждённом режиме | **запрещено по умолчанию** |
| RESTRICTED | только локально | только закрытый контур | **запрещено** |
| SECRET | без модели / спец. локальный модуль | **запрещено** | **запрещено** |

Публичный маршрут для CONFIDENTIAL/RESTRICTED/SECRET — **запрещён по построению**
(P0.4). Понижение класса моделью или из пользовательского ввода — запрещено.

## 2. Входы policy engine

Класс данных; tenant; проект; тип документа; тип задачи; регион хранения; провайдер;
модель; цель обработки; наличие договора/закрытого контура; стоимость; latency; SLA;
риск утечки; требование к воспроизводимости; влияние на вердикт; необходимость
передачи изображения/текста/метаданных; разрешение владельца данных.

## 3. Статусы маршрута

`LOCAL` · `PRIVATE` · `PUBLIC_MASKED` · `BLOCKED` · `HUMAN_REVIEW`.

## 4. Fail-closed

Если политика не может однозначно определить маршрут — вернуть `ROUTE_BLOCKED` с:
причиной; классификацией; требуемым разрешением; **отсутствием внешнего вызова**;
audit-event. Неизвестный класс / неизвестный tenant / неизвестный проект → BLOCKED.
Спорный или конфликтный вход → BLOCKED (не «наименее строгий» маршрут).

## 5. Профили маршрутов (P2)

`deterministic_text` (локально, без внешнего) · `local_ocr` · `local_vlm`
(advisory-only, для CONFIDENTIAL/RESTRICTED) · `private_vlm` (закрытый контур, при
подтверждённой политике, с audit) · `public_kimi_k3` (только PUBLIC/обезличенное) ·
`public_control_model` (только открытые данные, для сравнения) · `human_review`
(обязателен при неопределённости).

## 6. Инварианты (проверяются отрицательными тестами — Wave 2)

- Модель/пользовательский ввод/ответ модели **не могут** задать tenant, класс, маршрут, провайдера.
- Router **не** читает секреты, **не** меняет policy/verdict/ACL, **не** выбирает запрещённого провайдера.
- CONFIDENTIAL/RESTRICTED/SECRET → PUBLIC всегда `BLOCKED`.
- SECRET → любой модельный маршрут `BLOCKED`.
- Любой сбой (policy/mask/route/timeout/schema) → **никогда не PASS** (вердикт — движок).
