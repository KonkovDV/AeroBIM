# AeroBIM — IFC / IDS construction-pack checker

Checkpoint `NO_GO` until an independent labeled pack, two raters, an acceptance profile (public examination IDS for measurement; Samolet signature for deployment), and CDE proof. Not a CDE, not a model viewer, not an expert replacement.
Do not claim product accuracy >90%, customer SLA, native DWG, MEP delivered, or production-ready.
LLM/VLM never write `summary.passed` (ADR-001).

Internal working notes live outside this repository and must not be committed.
