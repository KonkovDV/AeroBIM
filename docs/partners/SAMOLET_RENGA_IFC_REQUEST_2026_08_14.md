Тема: AeroBIM / Задача 07 Техлаба — один IFC из Renga той же ревизии, что PDF

Добрый день,

для пилота МИК / Техлаб (Задача 07) нам нужен **один согласованный комплект**, а не доступ в ваши платформы.

Просим на NDA, без «починки под демо»:

1. **IFC, выгруженный из Renga** (схема в HEADER как есть: IFC4 или IFC4X3).  
2. Листы PDF/2D **той же ревизии**.  
3. Фрагмент ТЗ / EIR (хотя бы один раздел) с требованиями к ИМ.  
4. Куда вы импортируете BCF (название СОД: 10D или иное) — **имя инструмента**, не доступ в прод.  
5. Два инженера дирекции ИМ на adjudication TP/FP.

Не просим:

- отключать Tangl Control / Value / Power BI;  
- доступ к 10D API или «интеграцию за спринт»;  
- нативную модель «чтобы пересчитать объёмы»;  
- замену clash/BoQ.

Демо-файл в нашем репозитории — учебный IfcOpenShell, **не** ваша выгрузка. Официальные IDS МОГЭ имеют `ifcVersion=IFC4`; если Renga отдаст `IFC4X3`, контур честно не пройдёт молча — это ожидаемо.

С уважением,  
команда AeroBIM
