Команда AeroBIM вошла в пятёрку кандидатов по задаче №7 ГК «Самолёт» (программа «Техлаб Москва»). Просим подтвердить заинтересованность в **пилотной** проверке гипотезы:

> отдельный слой детерминированной cross-document / openBIM-проверки (IFC + чертежи + ТЗ + provenance + HITL) может сократить ручную сверку комплекта **до** передачи в строительный контур, без замены 10D СОД / 10D Качество и без авторизации Shared→Published.

Пилот предполагает:
- один тип проекта / ограниченный набор дисциплин;
- фиксацию baseline трудозатрат **до** измерений эффекта;
- экспертное подтверждение итоговых находок;
- явные условия остановки при отсутствии корпуса (см. меморандум AeroBIM §13).

Настоящее письмо **не** является обязательством закупки и **не** подтверждает достигнутую точность или экономию.
