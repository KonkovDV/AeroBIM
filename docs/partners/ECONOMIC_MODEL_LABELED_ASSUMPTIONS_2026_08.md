# Экономическая модель AeroBIM — помеченные допущения

**Дата:** 2026-08-04  
**claim_level:** labeled_forecast_only  
**closes_rt001:** false  
**Назначение:** критерии конкурса (рынок / окупаемость / инвестзапрос) — **не** утверждение о доказанной экономии на корпусе заказчика.  
**15.08:** не запрос раунда. Юрлица нет. Ask недели = слот демо + размеченный комплект.

> Разделение: *product claim* («система экономит 20%») запрещён без пилота.  
> *Помеченный расчёт* («если A, B, C — тогда Z ₽; проверить на пилоте») — обязателен для экспертизы заявки.

## 1. Регуляторный драйвер рынка (факты права)

| Акт | Суть для рынка | Проверка перед подачей |
|---|---|---|
| ПП РФ №331 | Обязательный ТИМ на ряде госзаказов (с 01.01.2022) | текст постановления / актуальная редакция |
| ПП РФ №2357 | Расширение ТИМ для застройщиков долевого МКД / малоэтажки (сроки 2024–2025) | актуальная редакция |
| ПП РФ №614 | Передача ЦИМ в экспертизу (с 01.09.2024) | актуальная редакция |
| ПП РФ №1236 | Ограничения на иностранное ПО для госнужд / госучастия | аргумент доступности vs Solibri/Navisworks |

**Гипотеза рынка (помечена):** государство сделало **обязательной модель**, но не сделало **обязательным качество согласования содержания** между моделью, чертежами, ТЗ и нормами. Между «модель сдана» и «комплект согласован» остаётся ручной труд нормоконтроля / ГИПа.

**Допущение D-DOM (уточнить источником перед подачей):** по публичным обзорам ЦК ТИМ Дом.РФ (~середина 2024) цифровизация у применяющих ТИМ сильнее на проектировании, чем на строительстве. Использовать только после сверки с первоисточником Дом.РФ / МИНСТРОЙ; до сверки — не цитировать как точную долю.

## 2. SAM снизу (формула)

```text
SAM_₽/год ≈ N_застройщиков × K_комплектов/год × H_часов_нормоконтроля × W_₽/час × S_доля_адресуемых_ошибок
```

| Символ | Смысл | Статус цифры | Пример для заявки (заменить) |
|---|---|---|---|
| N | застройщики / проектные институты под ТИМ-обязательствами в целевом сегменте | **A1 — нужна статистика** (ЕИС / Дом.РФ / отраслевой отчёт) | _TBD_ |
| K | комплектов (ПД/РД) на организацию в год | **A2 — допущение** | 12 |
| H | часов ручной сверки на комплект (до внедрения) | **A3 — baseline пилота** | 40 |
| W | полная ставка нормоконтролёра / ГИПа ₽/час | **A4 — рынок труда / HR заказчика** | 2 500 |
| S | доля часов, адресуемых классами ошибок AeroBIM на пилоте | **A5 — измерить на пилоте** | 0.20 |

**Пример (иллюстрация, не KPI продукта):**  
N=50, K=12, H=40, W=2500, S=0.20 →  
`50 × 12 × 40 × 2500 × 0.20 = 120 000 000 ₽/год` адресуемого труда в сегменте.

Каждая буква A1–A5 должна иметь источник или пометку «допущение / пилот».

## 3. Юнит-экономика пилота (один заказчик)

```text
экономия_пилота_₽ = H_baseline × W × S_measured − C_пилот
окупаемость_мес = C_внедрение / (экономия_мес)
```

| Статья | Помеченное значение | Примечание |
|---|---|---|
| Стоимость пилота (внедрение+обучение+разметка), C_пилот | **A6** | до первого платного пилота: услуги при MIT-ядре; open-core контур — обсуждение, не текущий SKU |
| Годовая подписка / сопровождение | **A7** | после пилота |
| Измеренная экономия часов | **только после baseline** (§8 `docs/docs.md`) | без baseline — не публиковать «окупаемость доказана» |

**Инвестзапрос (шаблон 3.6 для конкурсной заявки, не текущий ask недели):** сумма **A8** ₽ на 18 месяцев: (1) пилот с заказчиком, (2) норм-пак + журнал, (3) закрытый контур / реестр ПО, (4) команда (ГИП + 1 backend). Назначение средств — в заявке отдельной таблицей.  
**15.08:** раунд / SAFE не обещать (юрлица нет). Ask этой недели = слот демо + размеченный комплект.

## 4. Бизнес-модель (open-core)

| Слой | Открыто / закрыто | Монетизация |
|---|---|---|
| Детерминированное ядро Shared-gate | MIT (публичный репозиторий) | доверие / аудит |
| Норм-паки, адаптеры CDE, закрытый контур, SLA поддержки | коммерческие | подписка / проект |
| Разметка корпуса + экспертный журнал | актив заказчика / совместный | lock-in компетенций, не кода |

См. ADR-002 (**accepted**, граница) и [`COMMERCIAL_AND_OPEN_CORE_2026_08_14.md`](../gtm/COMMERCIAL_AND_OPEN_CORE_2026_08_14.md): до КТ#2 речь **A (MIT + услуги)**.

## 5. Что нельзя писать в заявке

- «Окупаемость N месяцев доказана» — без пилотных часов.  
- «Рынок X млрд» — без цепочки источников.  
- Любая связка с `macro_f1=0.86` или AECV `0.4325` как с денежным эффектом.
