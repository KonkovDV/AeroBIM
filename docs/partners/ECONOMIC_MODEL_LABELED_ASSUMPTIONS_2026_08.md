# Помеченная модель эффекта (A1–A8)

Это слой **допущений**, на который ссылается [`../docs.md`](../docs.md) §9.
Он не заменяет baseline пилота. Часы «до/после» на комплекте партнёра —
**нет данных**. Гипотеза пилота «снижение трудозатрат ≥20%» — цель проверки,
не заявленный результат.

Формула (без чисел):

```text
сэкономленные часы   = часы до − часы после
снижение трудозатрат = сэкономленные часы / часы до
```

Ячейки ниже **не заполнять выдуманными часами и рублями**. Пустое значение —
честный статус для Б4.

| ID | Допущение | Статус | Значение в git |
|---|---|---|---|
| A1 | Часы ручной проверки комплекта **до** системы | нет данных | — |
| A2 | Часы **после** (тот же freeze, тот же экспертный контур) | нет данных | — |
| A3 | Стоимость часа эксперта партнёра | нет данных | — |
| A4 | Число комплектов в день (5–10 в ТЗ) | цель ТЗ, не замер | не переносить в акт |
| A5 | Доля замечаний, пойманных до выдачи на площадку | нет данных | — |
| A6 | Число повторных заходов комплекта | нет данных | — |
| A7 | Порог «≥20%» из заявки / протокола пилота | гипотеза | не результат |
| A8 | ИС при призе (п. 6.3 Положения: исключительные права без доплаты) | риск программы | не «наш патентный забор» |

OSINT по рынку / SAM / штату заказчика — вторичка; в акт МИК не идёт.

Что нужно, чтобы строка перестала быть пустой: freeze комплекта; замер часов
**до** первого прогона; тот же протокол после; подпись эксперта партнёра.
