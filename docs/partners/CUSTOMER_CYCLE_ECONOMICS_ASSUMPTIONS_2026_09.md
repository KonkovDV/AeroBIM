# Минус один круг согласования — модель, не цифра в отчёте

Секунды парсинга на этот слайд **не ставим**. Метрика кресла техзаказчика —
дни цикла и стоимость денег (эскроу / переделка на площадке).

Формула для оспаривания **по строкам**, не целиком:

`экономия ≈ (снятые круги) × (календарные дни круга) × (стоимость дня комплекта)`

Ни один множитель в git **не измерен** на объекте заказчика. Связанная модель с
помеченными допущениями: [`ECONOMIC_MODEL_LABELED_ASSUMPTIONS_2026_08.md`](ECONOMIC_MODEL_LABELED_ASSUMPTIONS_2026_08.md).
Четыре проверки «заявленное vs записка»: [`../quality/CALCULATION_COMPARE_FOUR_CHECKS_2026_09.md`](../quality/CALCULATION_COMPARE_FOUR_CHECKS_2026_09.md).

| ID | Допущение | Кто опровергает | Если опровергнуто |
|---|---|---|---|
| E1 | Один лишний круг согласования РД на типовой секции существует | техзаказчик | модель обнуляется; остаётся дельта ревизий как инструмент аудита генпроектировщика |
| E2 | Длительность круга — **N рабочих дней** (N задаёт заказчик) | техзаказчик | подставить их N; не спорить «у нас 30 минут» |
| E3 | Стоимость дня комплекта — их внутренняя цифра (не публикуем) | техзаказчик / PMO | считаем только дни, без рублей |
| E4 | Система снимает **не больше одного** круга на эталонном корпусе после канонической пары ревизий | методика + книга замечаний | без эталона круг не считаем |
| E5 | Повторяемость на типовой секции > единичный дефект | направление ИМ (типизация) | тот же IDS/профиль; не «каждый раз заново руками» |

Экран «Эффект» сегодня: журнал HITL (подтверждено / отклонено). Это **не** дни
цикла СОД. Экран сравнения ревизий: новые / не воспроизведено / вернувшиеся.
«Не воспроизведено» ≠ «исправлено».

Ответственность за пропущенный дефект: эксперт остаётся на Shared-gate
(ADR-001). Система — ассистент, не замена экспертизы.
