# Письмо заказчику (скопировать)

Тема: Task 07 / КТ#2 — нужен согласованный комплект, профиль, два эксперта, цель СОД

Текст:

```
Коллеги,

мы на стадии доработки по задаче 07. Промежуточный показ — одна команда live CLI
на учебном комплекте (fail-closed, доказательная находка). Валидация эффективности
и внедрение не начаты. Checkpoint NO_GO, пока нет четырёх поставок с вашей стороны.

Просим к пилоту (не доступ в прод, не замена Tangl/10D):

1. Один согласованный комплект той же ревизии: ПД/РД + IFC (выгрузка Renga как есть,
   схема HEADER без «почините под демо») + 2D/PDF + фрагмент ТЗ/EIR.
2. Подписанный профиль приёмки (IDS / rule pack + approval_ref / pack_hash) —
   что считать ошибкой на этом объекте. Публичные IDS экспертиз не заменяют ваш пакет.
3. Два инженера-разметчика (adjudicators) на TP/FP по находкам.
4. Цель СОД для BCF: название системы и версия BCF, куда импортировать замечание
   (скрин/лог импорта — доказательство; не просим API 10D).

Плюс короткий signed scope: дисциплины, стадия, что не проверяем (DWG native,
MEP system-clash, CV как приёмка).

Без п.1–4 не мерим SLA ≤30 мин и interim TP≥0.60 на вашем комплекте.
Канал передачи — NDA, не публичный git.

Репозиторий: https://github.com/KonkovDV/AeroBIM
```

выдаём их за профиль приёмки «Самолёта». Нам не нужен большой контракт на
