# HTTPS и изоляция на демо-стенде

Слот **15.09** в календаре программы — **менторы**, локальный стенд и шаринг
экрана. Самостоятельная проверка заказчика к **14.09** — другой контур
(операторский time-boxed HTTPS или on-prem, если их контур примет образ).
Прямого контакта с Самолётом нет. 14.09 — финальная дата для заказчика.

| Тема | Что есть | Чем это не является |
|---|---|---|
| Транспорт | HTTPS на развёртывании, если стенд поднят с TLS; локальный `http://127.0.0.1` для оператора | сертификация, аттестация, ГОСТ ИБ |
| Хранение | объектный стор с `tenant_storage_prefix`; отчёты за хешем целостности | CDE, мультиарендный SaaS |
| ACL | `enforce_object_acl` — чужой объект даёт 404, не 403 | тенантный прод-контур |
| Данные канала | gitignored `files/` / `.local/`; в git нет имён, хешей и текста замечаний | «пакет обработан» |

Брендбук Самолёта на токенах `--vl-` **отложен** до после 15.09: контраст
`a11y-smoke` важнее совпадения оттенка. Умолчание «потом подгоним» здесь
зафиксировано как отказ, не как молчание.

Тестовый период **30–60 дней**, о котором говорили на созвоне 09.09, — это
процесс (стенд, журнал прогонов, rollback, обратная связь), **не** SLA и
не обещание поддержки, пока нет письменных ролей и контура. Облачные
адаптеры репозитория нельзя показывать как выполнение требования on-prem.

Пробный доступ к **14.09** (письмо организаторов): заказчик должен **сам**
загрузить контрольные данные трёх комплектов. Режимы — в
[`KT3_CUSTOMER_DELIVERY_14_09.md`](KT3_CUSTOMER_DELIVERY_14_09.md).
Исходящий ответ: [`KT3_ORGANIZER_REPLY_14_09.md`](KT3_ORGANIZER_REPLY_14_09.md).
