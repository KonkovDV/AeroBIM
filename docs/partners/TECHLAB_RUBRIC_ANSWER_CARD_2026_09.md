# Карточка рубрики (комиссия №7)

Пять кресел: два МИК, три Самолёта. На каждый критерий ТЗ — что показываем,
каким артефактом, какая граница заявления.

| Критерий ТЗ | Что показываем | Артефакт | Граница |
|---|---|---|---|
| Точность коллизий >90 % | Методика + числа на фикстуре AABB и открытом корпусе с n и интервалом Уилсона | экспорт слоёв отчёта; `docs/evidence/clash-measurement-slice-2026-08`; план `WP-R7a` | не корпус заказчика; не произносим «точность продукта» |
| Качество замечаний RU/EN | HTML/PDF `?locale=ru` (по умолчанию) и `?locale=en`; суть, пункт, локация | `GET /v1/reports/{id}/export/html?locale=` | машинные токены (`finding_id`, `rule_id`) не переводятся |
| Формат замечания 2.1.5 | триада или явный маркер «неполное замечание» | секция полноты в отчёте; `remark_completeness` в JSON | неполнота не выдумывает пункт |
| Подтвердить/отклонить до выгрузки | отклонённое вне списка замечаний, в секции «Отклонено экспертом»; BCF без отклонённых тем | HTML/PDF/BCF | запись не удаляется |
| Сравнение версий | API `revision-diff`; секция в отчёте — `WP-R12` (ещё не в этом срезе) | `GET .../revision-diff` | «не воспроизведено» ≠ исправлено |
| Расчётные ошибки | четыре строки сверки заявленных значений | план `WP-R13`; на канале `IfcReinforcingBar` = 0 | сверка, не пересчёт |
| Форматы RVT/NWD / 1,5 ГБ | fail-closed отказ + строка покрытия | паспорт форматов `WP-R14` (ещё не в этом срезе) | читаем IFC 2x3 и новее |

| Роли Эксперт / Пользователь | слои отчёта: служебное не мешает роли «Пользователь»; HITL в экспорте | HTML слои | слой ≠ вердикт |
| Три отчёта + пробный доступ к 14.09 | HTML выжимка на каждый слот канала; on-prem или time-boxed HTTPS | [`KT3_CUSTOMER_DELIVERY_14_09.md`](KT3_CUSTOMER_DELIVERY_14_09.md) · [`KT3_ORGANIZER_REPLY_14_09.md`](KT3_ORGANIZER_REPLY_14_09.md) | не GitHub; не демо-seed; не SLA 30–60 дней |

## Заготовки на острые вопросы

**«Ваша точность по коллизиям?»** На вашем комплекте не измеряли и заявлять
не будем. Измерено на фикстуре и на открытом корпусе; числа несут `corpus_kind`
и n. Чтобы измерить у вас: корпус, два размётчика, ослепление.

**«Сколько из наших замечаний вы нашли?»** У вас единица учёта — строка
требования чек-листа РД, у нас — находка по элементу. Построчный процент был
бы подгонкой. Инструмент сверки — кросс-уок по требованиям
([протокол](SAMOLET_RECONCILIATION_PROTOCOL_2026_09.md)).

**«Почему мы не видели результатов?»** Канал доставки — отдельный P0
([записка](DELIVERY_INTEGRITY_2026_09.md)). Коммит не является доставкой.

**«Два независимых разметчика?»** На ближайшем пилоте — один named expert по
выданному пакету (схема созвона 09.09). Это не precision. Два разметчика
остаются для publishable.

**«Почему не читаете RVT и NWD?»** Закрытые форматы; читаем IFC 2x3 и новее
(ответ 1.1.5). Непрочитанное стоит отдельной строкой с причиной.
