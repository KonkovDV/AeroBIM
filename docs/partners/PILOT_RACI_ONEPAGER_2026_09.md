# Рамка пилота (подписать или пилота нет)

Критерии успеха — подписываемые, не «точность выше 90%»:

1. Эксперт подтверждает **не менее N из первых M** находок (N/M согласовать;
   старт обсуждения: N=12, M=20).
2. Время до первого валидного замечания **не выше T** (T задаёт техзаказчик
   в днях цикла, не в секундах парсинга).
3. Falsification: нижняя граница Уилсона 95% precision первых 20 < 0,50 →
   продукт останавливаем. См. [`USER_JTBD_CONSTRUCTOR_EXPERT_2026_09.md`](USER_JTBD_CONSTRUCTOR_EXPERT_2026_09.md).

Кто подписывает, что пилот успешен: **акт площадки** (форма МИК M7 —
`VERIFY_WITH_OPERATOR`). Git форму Фонда не сочиняет.

## RACI (фамилии заказчика в git пустые)

| Работа | Капитан AeroBIM | Направление ИМ | Техзаказчик / эксперт-конструктор | Проектный офис | Куратор Фонда |
|---|---|---|---|---|---|
| Профиль IDS / ИТЗ (подпись) | C | **A** | C | I | I |
| Каноническая ревизия комплекта | C | C | **A** | I | I |
| Разметка TP/FP (два человека) | C | I | **R** | **A** (слоты) | I |
| HITL confirm/reject в контуре | R (движок) | I | **A** | C | I |
| Режим данных / NDA | C | C | I | C | **A** (эскалация) |
| Импорт BCF в СОД | C (файл) | I | I | **A** (какая СОД) | I |
| Акт пилота | C (приложение) | C | C | C | **A** (форма) |

R = делает, A = владелец, C = консультирует, I = информирован.
Ячейки «кто конкретно» заполняет владелец в исходящем, не в публичном MIT.

## Bus factor

Разработчик **один**. Если недоступен две недели: воспроизведение одной командой
с чистой машины офлайн; логика в CI; инвентарь архитектуры генерируется;
документация в репозитории. Это компенсация, не команда. Предсказуемость
поставки «обещали / сделали» на одном человеке — риск, не скрываем.

## Деградация

- Без ИИ-слоя система работает: LLM/VLM advisory; вердикт детерминирован.
- Недоступен наш сервис: эксперт работает как раньше; СОД и Tangl на месте;
  данные комплекта не в нашей прод-базе.
- SSO заказчика: `GET /v1/auth/bff` по умолчанию **501**. Лаб 403 для роли
  «Пользователь» на HITL — не промышленный IdP. **NOT_VERIFIED** как пилотный SSO.
