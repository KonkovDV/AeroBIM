# Краткий отчёт — AeroBIM

**Итог.** Есть честный рабочий показ «чертёж → проверка → замечание» и живое чтение фрагмента чертежа через Yandex Cloud. Итоговое решение — за правилами и человеком, не за моделью.

## Сделано

- Сквозной прогон: комплект документов → извлечение → сопоставление → замечание с привязкой к месту → отчёт.
- Чтение чертежа: в модель уходит фрагмент листа; на примере система верно нашла толщину 150 мм.
- Границы заявлены явно: нет обещания «точность 90%+», нет «понимает как инженер», нет подписи результата искусственным интеллектом вместо эксперта.
- Дальнейший план по зрению на чертежах разложен по этапам: что уже старт, что ещё нельзя называть готовым продуктом.

## На созвоне

1. Показать прогон с замечанием.  
2. Показать, что модель прочитала фрагмент.  
3. Зафиксировать ограничения и следующий шаг.

## Просьба

Жёсткая оценка: где убедительно для продукта, где ещё перегиб.
