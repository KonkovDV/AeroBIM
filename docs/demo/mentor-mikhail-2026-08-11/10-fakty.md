# Только факты

## 1. Сквозной прогон выполнен

- Вход: один комплект документов (чертёж, модель, правила).
- Результат: сформировано замечание и отчёт.
- Доказательство: `evidence/slice-summary.json`, `evidence/report.json`.

## 2. Есть привязка к источнику

- Замечание связано с конкретным местом на листе.
- Для просмотра удобнее `evidence/report.html`.
- Хэши входов зафиксированы в `evidence/slice-summary.json`.

## 3. Фрагмент чертежа прочитан внешней моделью

- Используется Yandex Cloud.
- В модель ушёл **фрагмент** листа: `evidence/crops/00-content.png`.
- В ответе чтения найдено значение **150 мм**: `evidence/vlm-result.json`.

## 4. Решение

- Итог принимает детерминированная проверка и эксперт.
- Модель выступает как подсказка и не подменяет подпись результата.

## 5. Границы (не заявляем)

- «Точность выше 90%» на данных заказчиков — не заявляем.
- «Модель понимает чертёж как инженер» — не заявляем.
- «Итог ставит искусственный интеллект» — не заявляем.
- «Готовое зрение продукта без эксперта» — не заявляем.

## 6. Проверка границ

- Список ограничений: `evidence/slice-LIMITATIONS.json`, `evidence/vlm-LIMITATIONS.json`.
- В пакете нет ключей и секретов; часть идентификаторов скрыта.
