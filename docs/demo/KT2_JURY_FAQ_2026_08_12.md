# KT#2 jury FAQ (2026-08-12)

## Можно говорить

1. Промежуточная версия на учебном (fixture) сценарии готова.  
2. Методика разметки и harness готовы; publishable-гейт на синтетике падает.  
3. IDS fail-closed; BCF ZIP структурно OK (T1); импорт в СОД — **NOT_VERIFIED**.  
4. Коллизии: измерено пересечение AABB на синтетическом IFC (n=6), не продукт >90%.  
5. Наложение ошибки на чертёж — детерминированные рамки, не CV.  
6. VLM/LLM — advisory; `summary.passed` не меняют.  
7. Checkpoint **NO_GO**, пока нет корпуса / norm pack / MEP scope заказчика.  
8. Пять KPI Техлаба инструментированы; цифры customer — после intake.  
9. МИК M3–M6 eng-ready; M2/M7/M8 — оператор/заказчик.  
10. Подпись коммитов (A4) активна; handoff проверяется `verify_kt2_handoff`.

## Нельзя говорить

1. Точность >90% / «по ТЗ коллизии закрыты».  
2. SLA ≤30 мин доказан на комплекте Самолёта.  
3. Экономия ≥20% доказана.  
4. Native DWG готов.  
5. MEP system-aware clash сдан.  
6. BCF готов к СОД / CDE-ready.  
7. OIDC BFF production-ready (сейчас 501 stub).  
8. CV / VLM «понимает чертёж как инженер».  
9. Checkpoint GO / «можно принимать в проде Самолёта».  
10. Каталог ≥20 ошибок «подтверждён заказчиком» без `customer_confirmed`.

## Короткий ответ на «почему NO_GO?»

NO_GO — не «система сломана», а «нет подписанного evidence заказчика (RT-001/002/003)». Fixture GO и методика — да.

## Самолёт / Tangl / 10D (срез 14.08.2026)

Можно:

1. «Стек заказчика публично Renga + Tangl + 10D. Tangl проверяет **модель**; AeroBIM — **комплект**.»  
2. «Официальные IDS МОГЭ = `IFC4`. Если `FILE_SCHEMA` другой (в т.ч. `IFC4X3`), контур fail-closed. Публичный комплект Renga 8.7 ПНСТ 909 на этой машине измерен как `IFC4` — это **не** Самолёт.»  
3. «Демо-IFC в репо — IfcOpenShell fixture, не выгрузка Renga. Прогон издателя: `run_renga_export_probe`. Выгрузка Самолёта — intake.»

1. «Интегрированы с Tangl / 10D / S.Project.»  
2. «Заменим Tangl Control / Value / Power BI.»  
3. «Закрыли ЦИМ АГР Москвы» (профиль CUT).  
4. Называть текущие должности ой / а после ухода или смены блока.
