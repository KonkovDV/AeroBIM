# ADR-005: производные данных заказчика и публичный MIT

## Context

Репозиторий публичный, лицензия MIT. Публикация в git необратима без
переписывания истории (это решение владельца и юрслужбы, не хук CI).
В канале партнёра могут быть внутренние регламенты застройщика. Письменного
режима данных на 04.09.2026 **нет** (запрос 28.08; ответ — нет данных).

## Decision

1. В публичный git **не** кладём: имена объектов, шифры комплектов, пути шары,
   кадастр, хеши живых файлов, пофайловые реестры, дефекты конкретной выгрузки
   как «их косяк», цитаты внутренних регламентов.
2. Исходящие письма с цензом живут в **`.local/partners/`** (gitignore) или в
   соседнем приватном дереве `../AeroBIM-private/`. Git почту не отправляет.
3. Повестки коллов 15.09 с аудитом канала — тот же контур, не `docs/partners/`
   в origin.
4. Самоограничение не ждёт ответа: производные канала не коммитятся, пока нет
   письменного режима.
5. Уже закоммиченные носители (исторические пины) **не** удаляются скрытой
   переписью истории без явной команды владельца. Новый текст не добавляет
   фактов канала.

## Consequences

- Формула речи: «данные — критический путь; запрос от 04.09; план Б работает
  с 09.09». Не «ответственность полностью на стороне заказчика».
- Демо 15.09 / демо-день: локальный стенд и шаринг экрана.
- Checkpoint **GO**; customer_go false.
