# DWG — три варианта для защиты (решение владельца)

ТЗ прямо называет DWG в «Загрузка». Сейчас: **fail-closed** (`UNSUPPORTED_NATIVE_FORMAT`). В матрице требований это читается как «не умеем», пока нет письменного выбора A/B/C.

## Сравнение

| | **A. Лицензия ODA** | **B. Конвертация (согласованный pipeline)** | **C. Обоснованный отказ** |
|---|---|---|---|
| Суть | Native/near-native DWG через ODA Teigha/Drawings | Реальный DWG → DXF/IFC/PDF по согласованному пути; измерить потери | Не обещать DWG; IFC+PDF покрывают заявленные проверки |
| Стоимость | **ТРЕБУЕТСЯ ОТ ВЛАДЕЛЬЦА:** коммерческий прайс ODA (часто от десятков тыс. USD/год; точная цифра только из КП) | Инженерное время + 1–2 эталонных DWG от заказчика/открытого корпуса | ~0 лицензий; стоимость — ясность в ТЗ/матрице |
| Срок | Получение лицензии + NDA: обычно **недели–месяцы** | MVP измерения потерь: **1–2 недели** при наличии файла | Документ готов **сейчас** |
| Интеграция | Новый adapter под **существующий** ingestion port; DI wiring | Adapter convert + provenance до исходного DWG hash | Без нового порта |
| Что теряем | Мало (если ODA полный) | Сущности/атрибуты/слои — **измерить** на эталоне; без замера не обещать | Нативный DWG geometry/layers; всё, что есть только в DWG и нет в IFC/PDF |
| Риски | Бюджет; зависимость; IP | «Конвертировали = умеем DWG» overclaim | Конкуренты с native DWG на питче |

## Абзацы для защиты

**A.** «Готовы идти в ODA при утверждённом бюджете: стоимость и срок — по коммерческому предложению; интеграция — адаптер к текущему ingestion port без новых доменных портов.»

**B.** «Пока нет ODA: берём согласованный конвертер, прогоняем эталонный DWG, публикуем таблицу потерь сущностей/атрибутов с provenance до исходного файла. Без этой таблицы не заявляем покрытие DWG.»

**C.** «При наличии IFC и PDF комплектности/свойств/cross-doc/IDS достаточно для текущего Shared-gate контура. Заказчик теряет проверки, которым нужен именно native DWG (слои AutoCAD, неэкспортированная геометрия). Это честный OUT до решения по A/B.»

## Рекомендация инженерии (не решение)

До ответа Самолёта и бюджета: держать **C** в матрице ТЗ + параллельно готовить протокол замера **B** на первом реальном DWG. **A** — только после цифры от владельца.

**ТРЕБУЕТСЯ ОТ ВЛАДЕЛЬЦА:** выбрать A, B или C письменно; для A — бюджет/КП ODA.
