# К4: нулевой вход, не запрос инвестиций

К4 — **потенциал** тиража. Часы A1–A8 по-прежнему пустые. Выручка в git = 0.
`k4_revenue_claimed() == False`.
`k4_asks_customer_capex() == False`.
`k4_offsets_partner_ifrs_loss() == False`.

Аргумент «инвестируйте в инновации» **умер** после МСФО группы за 1П2026
(опубликовано 28.08.2026). Компания в убытке, режет расходы и гасит долг.
Любое предложение с бюджетом вперёд читается как непонимание обстановки.

## Что работает в речи

1. **Нулевой вход на MVP.** Не CAPEX, без внедрения в контур, без лицензионной
   стены. Веб-доступ и файловый обмен (п. 2.2.2 ТЗ).
2. **Оплата по подтверждённым находкам или возврат** — план речи, не
   подписанный SKU. Не заполнять этим A1–A8.
3. Просить у партнёра **не бюджет**, а данные и два часа эксперта на разметку.
   Это закрывает RT-001, не кассовый разрыв партнёра.
4. Переделки на стройке при падающей выручке бьют туда же, где уже болит.
   Узкий шов комплекта, не «мы спасём экономику проекта».

Цифра одна по календарю, **знаки разные**. Перепутать МСФО и РСБУ перед креслом
техзаказчика — потерять доверие за одну фразу.

Чистый корпоративный долг в прессе расходится по определениям. В git **не
кодируем** спорную строку долга. EBITDA / скорр. EBITDA тоже не клеим в наш
эффект.

Программа ИИ партнёра: публичная оценка **около 200 млн ₽ в год** (ComNews,
21.05.2026) с начала 2025 — **их** контур, не AeroBIM. 200 млн против убытка
22,3 млрд — меньше процента. Мы добавляем узкий участок к уже начатой
программе, не заменяем её и не «спасаем P&L».
