## Протокол пересчёта

1. Выгрузить тексты в `.local/evidence-sources/spb-ar/` и `amur-errors/` (не GH без нужды).  
2. Классифицировать каждую строку: обнаруживается / условно / вне области / не обнаруживается (тот же словарь Exp B).  
3. Отчёт: n, доли, оговорка «три органа ≠ одна популяция».  
4. Обновить `EXPERIMENT_B_…`, Friday speech, demo-format, baseline PDF.  
5. **Не** сравнивать % АР СПб с % КР Киров как «рост продукта» без оговорки.

## Предварительная разведка СПб АР (публичный индекс)

На индексе СПб в разделе АР видны как минимум:

1. Текст ≠ графика / отметки / уклоны / разрезы↔планы → класс **обнаруживается** (уже в Мордовии).  
2. Цоколь / утеплитель (384-ФЗ) → **условно** (norm-pack).  
3. Высота здания при разных отметках земли → **обнаруживается** (близко к этажности).  
4. Крепление наружных лестниц → **вне области** / условно.

Полный n после выгрузки карточек — владелец/следующий проход.
