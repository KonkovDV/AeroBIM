# Эксперимент А — статус

**Первая строка (обязательная оговорка):** разбор находок, когда будет выполнен, — `AUTHOR_CLAIM`, не адъюдикация независимого эксперта. Доля ложных срабатываний — предварительная и подлежит перепроверке на пилоте.

## Почему NOT_RUN

Реестр экономически эффективной ПД повторного применения Минстроя **публикует сведения о проектах**, а не свободный архив IFC/PDF для скачивания. Передача документации — через лицензионный договор с правообладателем (см. письма Минстроя / ПП РФ № 389). В открытом доступе нет готового комплекта с IFC, который можно честно прогнать как «чистый после положительного заключения» без нарушения лицензии.

Попытка подменить чужим open IFC **запрещена**: это уже не эталон «человек сказал — замечаний нет».

## Что нужно для запуска (ТРЕБУЕТСЯ ОТ ВЛАДЕЛЬЦА)

1. Выбрать 1 объект из реестра Минстроя (URL/ID записи).  
2. Получить комплект легально (лицензия / открытая выкладка правообладателя).  
3. Положить файлы в `.local/minstroi-reuse/<id>/` (не в GH без проверки ToS).  
4. Зафиксировать фактический состав: PDF / DWG / IFC / иное.

## Протокол (когда пакет появится)

1. Перечислить проверки, которые **можно** запустить при данном составе; явно перечислить **не** запущенные и почему (нет IFC → нет clash/IDS; только PDF → partial drawing; DWG native → fail-closed).  
2. Прогон: commit SHA, config, hash комплекта, оборудование, wall-clock.  
3. Каждую находку: (1) верная/пропущенная · (2) вне области · (3) ложное — **AUTHOR_CLAIM**.  
4. Доля ложных = n3 / всего.
