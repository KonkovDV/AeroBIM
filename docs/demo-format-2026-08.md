# Формат демо и два обходных эталона (П4)

Канон для КТ#2 / трекера. Каркас критичности также в  
[`customer-discovery/demo-format-2026-08.md`](customer-discovery/demo-format-2026-08.md).

## 1. Сценарий демо (30–40 минут)

| Мин | На экране | Что говорим |
|---:|---|---|
| 0–2 | Титул: AeroBIM · Техлаб · задача Самолёта · **Checkpoint NO_GO** | Кто мы; приз = оплачиваемый пилот; сегодня — протокол измерения, не «готово к промышленной». |
| 2–5 | Claims Lock (кратко): что **не** заявляем | Нет >90%, нет native DWG, нет MEP as OK, нет calc as solver. |
| 5–8 | Шкала критичности (таблица §2) | Своя шкала по **последствию**, не по внутренним кодам. |
| 8–12 | Правило 3 категорий (§4) | Находка вне заключения ≠ авто-ошибка системы. Категорию ставит эксперт. |
| 12–18 | Live/запись: analyze одного открытого пакета (IFC+IDS или wall-guid) | На экране: findings + coverage map; явно: fixture ≠ заказчик. |
| 18–26 | Эксперимент Б: ≈8→17→25 % + КР условно ≈33 % (17 norm + ≈17 неподтв. полнота) | Три раздела; оговорка органов; Task 3. |
| 26–30 | Эксперимент А: статус NOT_RUN / таблица если есть пакет | Честно: без комплекта Минстроя прогона нет. |
| 30–34 | Форма сравнения (§5) + сопоставление со шкалой заказчика (§3) | Как заполним на их ноутбуке. |
| 34–37 | Вариант для экспертизы (§6) | On-prem; они загружают; мы ничего не забираем. |
| 37–40 | Q&A → слот пилота / имя владельца процесса | Успех демо = следующий шаг, не «продажа точности». |

Буфер ±3 мин: если нет live — запись + evidence bundle wall-guid.

## 2. Шкала критичности (по последствию)

| Уровень | Определение |
|---|---|
| **Блокирующее** | Препятствует положительному заключению **или** влияет на безопасность |
| **Существенное** | Переделка раздела / повторный цикл согласования |
| **Несущественное** | Оформление / комплектность |

## 3. Сопоставление со шкалой заказчика

1. До демо: получить их названия уровней (или «критичность 1–3 / А–В–С»).  
2. Заполнить матрицу соответствия **один раз** с экспертом заказчика (не угадывать):

| Наша шкала | Их уровень (заполнить на месте) | Правило перевода |
|---|---|---|
| Блокирующее | | |
| Существенное | | |
| Несущественное | | |

3. В отчёте пилота публиковать **обе** колонки; без матрицы — не агрегировать «совпало по критичности».

## 4. Правило разбора расхождений (произнести вслух)

Находка, которой нет в заключении / эталоне, **не** считается ошибкой системы автоматически. Эксперт относит к:

1. **обоснованная** (и, вероятно, пропущенная человеком / вне фокуса заключения);  
2. **вне области** той проверки / того комплекта;  
3. **ложное срабатывание**.

Без этого правила демо превращается в спор: заключение экспертизы в глазах собеседника авторитетнее отчёта системы.

## 6. Вариант для организаций экспертизы

Они **не могут** передать документацию заявителя: принадлежит заявителю, экспертиза связана конфиденциальностью, заключение уходит в ЕГРЗ.

Формат: система ставится **на их стороне** (ноутбук / контур). Они загружают сами. Мы ничего не забираем. Нужны **40 минут** и их ноутбук. Это снимает вопрос ИБ до того, как он задан.

## 7. Результаты экспериментов

### 7.1 Эксперимент Б — покрытие vs перечни (КР + АР + ВК)

SSOT: [`evidence/EXPERIMENT_B_TYPICAL_REMARKS_KR_COVERAGE_2026_08.md`](evidence/EXPERIMENT_B_TYPICAL_REMARKS_KR_COVERAGE_2026_08.md).

**Произнести:** КР ≈8 % «обнаруживается» (n=24; Task 3) → 17 % АР → 25 % ВК; разница в доле сверки, не в «качестве системы»; условно КР ≈33 % = ≈17 п.п. norm-pack + ≈17 п.п. неподтверждённой полноты/содержания; ВК ещё ≈13 п.п. = федеративная модель (RT-003, на open не подтверждено). Не говорить «закрыли 25 пунктов полноты».

| Блок | Орган | n | обнар. | условно | Примечание |
|---|---|---:|---:|---:|---|
| **Киров** 1. КР | Киров | 24 | **≈8,3 %** | **≈33 %** | Task 3: 2 строки на open/synthetic; область ≠ типовые КР-расчёты |
| **Мордовия** 2. АР | Мордовия | 12 | **17 %** | **25 %** | хрупко (~8,3 п.п./строка) |
| **Мордовия** 3. ВК | Мордовия | 16 | **25 %** | **50 %** | вне обл. **13 %** после перепроверки; RT-003: **13 п.п.** |

Киров и Мордовия разделены: не один эксперимент. Произнести ≈8 → 17 → 25 %, не «закрыли 25 п.п. полноты».
