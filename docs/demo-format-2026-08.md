# Формат демо и два обходных эталона (П4)

Канон для КТ#2 / трекера. Каркас критичности и правило 3 категорий также в  
[`customer-discovery/demo-format-2026-08.md`](customer-discovery/demo-format-2026-08.md).

## Шкала критичности (по последствию)

| Уровень | Определение |
|---|---|
| **Блокирующее** | Препятствует положительному заключению **или** влияет на безопасность |
| **Существенное** | Переделка раздела / повторный цикл согласования |
| **Несущественное** | Оформление / комплектность |

## Правило расхождений (произнести на демо)

Находка, которой нет в эталоне, **не** = автоматически ошибка системы. Эксперт относит к:

1. верная, пропущенная человеком;  
2. вне области той проверки;  
3. ложное срабатывание.

## Путь A — инверсный тест на «чистом» комплекте (лучше для демо)

**Идея.** Комплект из реестра экономически эффективной ПД повторного применения Минстроя **по определению** прошёл госэкспертизу с положительным заключением → эталон человека: «замечаний, блокирующих положительное заключение, не осталось».

**Протокол**

1. Зафиксировать URL / ID комплекта, раздел, лицензию/ToS, дату скачивания.  
2. Прогнать AeroBIM на выбранном разделе (локально).  
3. Каждую находку разметить одной из трёх категорий выше.  
4. Свести:

| Показатель | Значение |
|---|---:|
| Находок всего | |
| Кат.1 (верная, пропущенная) | |
| Кат.2 (вне области) | |
| Кат.3 (ложное) | |
| Доля ложных (кат.3 / всего) | |

**Что это даёт.** Прямую частоту ложных срабатываний на документе, признанном чистым — главный страх автоматической проверки.  
**Чего не даёт.** Publishable precision на корпусе Самолёта; закрытие RT-001.

**ТРЕБУЕТСЯ ОТ ВЛАДЕЛЬЦА / оператора:** выбрать 1 комплект из реестра Минстроя с доступным IFC/разделами в окне 48 ч; положить исходники в `.local/` (не в GH без проверки лицензии).

## Путь B — покрытие против перечня типовых замечаний (в пакет КТ#2)

**Идея.** Публичные перечни типовых замечаний госэкспертиз = внешний человеческий каталог классов.

**Протокол**

1. Зафиксировать источник перечня (орган, URL, дата).  
2. Для каждого типа замечания в выбранном разделе:

| Тип из перечня | Обнаруживаем в принципе? | Нужны какие исходные данные? | Не обнаруживаем / почему |
|---|---|---|---|
| | да / частично / нет | | |

**Что это даёт.** Карту покрытия против внешнего эталона (честная альтернатива «N норм в базе»).  
**Чего не даёт.** Числа precision/recall на размеченном корпусе.
