# Customer discovery call script

**claim_level:** outreach template only  
**Adapted from:** [`docs/customer-discovery/call-script-ru.md`](../customer-discovery/call-script-ru.md)

Tone: calm first touch. Do **not** lead with a list of what you will not promise — only if asked.

| Say aloud | Remember |
|---|---|
| «Team AeroBIM / Techlab Moscow track — Samolet task context.» | Do not start with architecture and test suites. |
| «We are not asking you to hand over the full package cold. We propose ~40 minutes on your side: system local, you load a section yourselves.» | Expertise orgs → on-prem. Design orgs → archive under their NDA. |
| «How do you reconcile model vs drawings vs TZ today — mostly manual, or already automated somewhere?» | Listen. Do not interrupt with a feature list. |
| «Fitness-for-purpose of documentation stays with your specialist — we surface matches and gaps against your reference.» | Honest line. Do not read a forbidden-claims list unless asked. |
| «Goal of this call: a 40-minute slot, or the name of the colleague who can schedule it.» | Success = slot or name, not «I'll send a deck» with no next step. |
| If «send materials»: «I will. What matters more — how it sits in your contour, or what it finds on a completed reference?» | Routes to one-pager vs demo scenario. |
| If «what accuracy?»: «On your package I do not know — that is why we propose measuring where a reference already exists.» | Never quote 90%, AECV, or fixture P/R as product accuracy. |
| If «we already check the model»: «Then the useful conversation is package reconciliation: drawing↔model, model↔TZ, values↔calculation.» | Do not name Techlab competitors. |

**Do not invent customer orgs or call outcomes in git.** Track outreach in a private / `.local` file; use [`CUSTOMER_OUTREACH_TRACKER_TEMPLATE.csv`](CUSTOMER_OUTREACH_TRACKER_TEMPLATE.csv) as an empty schema only.
