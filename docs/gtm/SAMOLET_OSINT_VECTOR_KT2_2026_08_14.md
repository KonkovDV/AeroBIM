# Самолёт OSINT + оптимальный вектор AeroBIM

**Срез:** 14 августа 2026.  
**Режим:** evidence-first, Red Team hygiene.  
**Не дублирует** июльский deep dive [`../samolet.md`](../samolet.md) — дополняет стек Renga/Tangl, смену ИТ-кураторов, НПА августа 2026 и монетизацию.

## 0. Вектор (одна фраза)

AeroBIM — **fail-closed слой проверки комплекта** (чертёж ↔ IFC ↔ ТЗ ↔ расчёт, provenance, официальный IDS МОГЭ, честный IFC4 vs IFC4X3) **после выгрузки Renga и рядом с Tangl Control**, не вместо них и не вместо 10D.

Продаём дирекции информационного моделирования и Задаче 07 Техлаба. Не продаём замену 10D ИТ-блоку Семенова и не продаём clash/BoQ против Tangl.

## 3. Стек, который уже стоит (не гипотеза «они на Revit»)

```text
Renga (проект / документация)
    → IFC (схема как в HEADER; публичный Renga 8.7 ПНСТ 909 на этой машине = IFC4, не IFC4X3)
        → Tangl Control  — проверка модели / clash / атрибуты
        → Tangl Value    — объёмы / CIM→BoQ   [у Самолёта публично акцент на данных + Power BI]
        → 10D СОД / S.Project / S.Control — маршрут, качество площадки
            → AeroBIM (гипотеза пилота) — комплект: PDF↔IFC↔ТЗ↔расчёт + IDS fail-closed
```

| Слой | Кто закрывает | AeroBIM делает | AeroBIM **не** делает |
|---|---|---|---|
| Авторская модель | Renga | Честно падать, если схема ≠ IDS (`IFC4` ≠ `IFC4X3`) | Плагин Renga, замена САПР |
| Проверка модели | Tangl Control | Не конкурируем | Clash-as-a-service |
| Объёмы | Tangl Value | Не конкурируем | Смета / BoQ |
| Визуализация BIM+BI | Tangl × Power BI | Не конкурируем | Дашборды ОТ |
| СОД / маршрут | 10D | BCF ZIP структурно (T1); импорт = NOT_VERIFIED | «integrated with 10D» |
| Комплект до экспертизы/АГР | **дыра** | Shared-gate, provenance, IDS МОГЭ, overlay на лист | Подпись Shared→Published |

**Честность демо:** `samples/ifc/walls-multi-entity.ifc` — IfcOpenShell 0.8.4, `FILE_SCHEMA(('IFC4'))`, имя проекта «Samolet Multi Fixture». Это **не** выгрузка Renga. Публичный образец издателя ПНСТ 909 (Renga Professional 8.7, `FILE_SCHEMA=IFC4`) — `run_renga_export_probe`, бинарник gitignored, **не** Самолёт. Выгрузка Самолёта — intake.

## 5. Боли Самолёта и отрасли (проверяемые)

### 5.1 Боли, которые ТЗ №7 уже назвало

Повторяемый поток ПД/РД; расхождение чертежа и модели; «норма устарела»; коллизии без provenance; эксперт тонет в FP; SLA комплекта.

### 5.2 Боли, которые стек **не** закрывает

| Боль | Почему Tangl/10D/Renga не закрывают | Почему AeroBIM (гипотеза) |
|---|---|---|
| IFC-схема Renga vs IDS МОГЭ `ifcVersion=IFC4` | IfcTester 0101 считает версию метаданными → **тихий pass**, если схема другая | Fail-closed 14.08 на токене. Издательский Renga 8.7 ПНСТ 909 на этой машине измерен как **IFC4** (не IFC4X3). Это не Самолёт |
| Чертёж PDF ≠ свойство IFC ≠ строка ТЗ | Control смотрит модель; 10D хранит файл | Кросс-документ + overlay на лист |
| Устаревшая ссылка ГОСТ 21.101-2020 в требованиях АГР | Вендоры модели это не ловят как пакет | `AEROBIM-NORM-SUPERSEDED` (механизм, не «соответствуем ГОСТ») |
| Нет подписанного профиля приёмки | EIR в PDF | RT-002 OPEN — без Самолёта не закрыть |
| Акт МИК vs «>90%» на слайде | Карточка конкурентов врёт так же | Publishable-гейт + Claims Lock |

### 5.3 Отрасль (не только Самолёт)

- **ЦИМ АГР Москва:** с **02.04.2026** IFC обязателен; с **29.06.2026** нужна ссылка на **положительный** отчёт «Проверки ЦИМ» на [stroimprosto.mos.ru](https://stroimprosto.mos.ru/lk/cimcheck). Полный профиль `moscow_agr` у нас **CUT** (freeze). Класс 1 на fixture — не АГР delivered.
- **ПП 331 + 614:** ИМ обязательна **только в случаях 331** (ст. 57.5 ГрК); 614 задаёт правила/форматы, не новые случаи. Приказ Минстроя «состав ЦИМ к графике ПД» на 14.08.2026 — **проект ID 155923, не НПА** (не цитировать как «усиление с 01.03.2026»). Типичный отказ экспертизы — экспорт и расхождение с графикой, не «нет clash-движка».
- **ГОСТ Р 21.101-2026** с 01.04.2026 (GUID документа п. 8.2.4) — механизм provenance, не «соответствуем стандарту целиком».
- Девелоперы режут штат / требуют AI с рублёвым эффектом → покупают **модуль в существующий стек**, не пятую СОД.
- ПИК закрывает автоматизацию **внутри Revit** (PikTools). Самолёт на **Renga**. Чужой Revit-плагин Самолёту не нужен.

## 7. Почему этот вектор совпадает с кодовой базой

Уже в дереве (не обещание):

- Shared-gate + ADR-001 (advisory не пишет `summary.passed`).
- IDS fail-closed: SKIPPED и mismatch `ifcVersion` → FAILED (кейс 0101 закрыт сознательно).
- Provenance находки → лист PDF / GUID IFC.
- BCF 2.1 ZIP структурно (T1), не CDE-ready.
- Overlay рамок на чертёж (детерминированный, не CV).
- Публичные IDS МОГЭ как engine coverage, не «норм-пак Самолёта».
- Эксперимент A: Renga ПНСТ 909 (ToS GO) — 18/22 IDS, не продукт.
- Open-core граница ADR-002: MIT ядро vs commercial adjudication / CDE T2 / on-prem.

Freeze **запрещает** то, что убьёт вектор: адаптер Tangl, порт 10D, полный `moscow_agr`, native DWG, MEP system-aware, новые DI.

Следствие 14–20.08: **не писать интеграции**. Писать речь, интейк и матрицу так, чтобы жюри/трекер не услышали «заменим Tangl».
