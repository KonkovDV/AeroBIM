# Нормативная база 2026 — срез для продукта

Перепроверять перед каждой публикацией. Источник текста стандарта для 21.101-2026: официальный PDF / СПС (приказ Росстандарта 12.02.2026 № 129-ст).

| Норматив | Дата / статус | Что затрагивает в AeroBIM |
|---|---|---|
| **ГОСТ Р 21.101-2026** | В силу **01.04.2026**; взамен 21.101-2020 | Шифры/марки (прил. А, табл. В.1: **ПБ, ПС, ОС**, **ОДД, МБТ**…); ревизии §7; электронный пакет / **GUID документа** п. **8.2.4**; комплектность; запрет overclaim УКЭП |
| **ГОСТ Р 21.101-2020** | Superseded с 01.04.2026 | Комплекты, разработанные **до** 01.04.2026 — label `21.101-2020` через config |
| **ПП РФ № 87** | ред. от 21.10.2025; действует до 01.09.2028 | Состав/содержание разделов ПД; Exp B / completeness |
| **ПП РФ № 145** | правки 26.11.2025; пакет с 01.03.2026; коэф. платы с 20.01.2026 | Экспертиза / коммерческий контур (не runtime) |
| **ПП 331** | ТИМ на госзаказе с 01.01.2022 | Контекст пилота |
| **ПП 2357** | застройщики долевого МКД с 01.07.2024 | Контекст заказчиков |
| **ПП 614** | ЦИМ в экспертизу с 01.09.2024 | IFC/модель в экспертизе |
| **ПП 1236** | ограничение иностранного ПО для госнужд | Не заявлять импортозамещение как преимущество |
| **ЕЦПЭ** | ЛК экспертизы, загрузка, замечания, заключение | Целевой контур выгрузки BCF |
| **63-ФЗ + Минстрой 4420-КМ/14** | УКЭП / ИУЛ | Claims Lock: никогда «УКЭП проверена» |
| **Смежно 01.09.2026** | аттестация проектировщиков МЧС (флаг) | Вне runtime; следить в governance |

## Правило редакции 21.101 (конфиг)

Файл: [`samples/config/documentation-standard-edition.json`](../samples/config/documentation-standard-edition.json).

Inventory может задать `package_developed_on` + rule → поле `documentation_standard_edition` в отчёте комплектности.

## Запрет заявлений

Не заявлять полное соответствие ГОСТ Р 21.101-2026. Допустимо: конкретный механизм + конкретный пункт (см. N-2 / `docs/docs.md`).
