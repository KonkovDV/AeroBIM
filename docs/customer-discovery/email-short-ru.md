# Короткое письмо — тело для копирования

> Оператор: ниже только текст письма. Не копировать этот блок и заголовок файла.

## Вариант A — негосударственная экспертиза

**Тема:** 40 минут на вашей стороне — без передачи комплекта наружу

```
[Имя Отчество / Добрый день],

[OPERATOR_NAME], команда AeroBIM. Мы участники программы «Техлаб Москва»
Московского инновационного кластера, задача ГК «Самолёт» — проверка
согласованности проектной и рабочей документации.

[Одна строка про вас: сайт / аккредитация / специализация.]

Комплект заявителя забирать не просим. Предлагаем другое: разворачиваем
систему у вас (локально), вы сами загружаете один уже проверенный раздел,
за 40 минут смотрим совпадения с вашим эталоном, лишние срабатывания и
пропуски. Решение о годности документации остаётся за вашим специалистом.

Если интересно — ответьте удобным временем или коротким звонком.

[OPERATOR_FULL_NAME]
команда AeroBIM, программа «Техлаб Москва»
Московский инновационный кластер
тел.: [ТЕЛЕФОН]
github.com/KonkovDV/AeroBIM

Если тема не актуальна — ответьте одним словом, больше не побеспокоим.
```
