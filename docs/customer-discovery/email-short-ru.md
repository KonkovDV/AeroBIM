# AeroBIM — короткое письмо (Claims Lock)

Тема: Демо проверки комплекта ПД/РД в закрытом контуре (без замены СОД)

Здравствуйте!

Мы — команда AeroBIM: **открытый исходный код (MIT)**, детерминированная проверка комплектов ПД/РД (IFC, IDS, PDF, evidence). Каждое замечание — со ссылкой на доказательство. LLM только помогает сформулировать текст; **проверяет движок**, решение остаётся за экспертом.

Предложение: короткое демо на **вашем завершённом обезличенном комплекте** (NDA, закрытый контур). Особенно ценен **архивный проект вместе с заключением экспертизы** — это позволяет сравнить наши находки с человеческим эталоном без работы на «живом» объекте.

Мы **не** обещаем: точность >90%, «ИИ вместо эксперта», готовность к промышленной эксплуатации, цифры чужих бенчмарков как точность продукта.

Если интересно — ответьте удобным временем. Отправка только после подтверждения оператором.

С уважением,  
AeroBIM
