# AeroBIM — развёрнутое письмо (черновик)

Тема: Пилот сравнения замечаний на завершённом проекте (IFC/PDF/расчёты)

Здравствуйте!

AeroBIM — система инженерной проверки комплектов проектной документации. Детерминированный движок владеет техническим verdict; LLM/VLM — только advisory (не ставит `summary.passed`).

## Проблема

Повторные замечания экспертизы, коллизии, несогласованность IFC/IDS/чертежей/расчётов, ручная сверка evidence.

## Что уже есть (engineering)

- IFC validation / IDS (где подключено)
- cross-document consistency checks на fixture пакетах
- BCF ZIP structural; CDE import — не доказан
- capability honesty API и Claims Lock

## Чего нет / не обещаем

- точность продукта >90%
- подтверждение на любом комплекте заказчика без корпуса и adjudication
- SLA ≤30 минут как универсальный клиентский SLA
- нативный DWG
- независимая проверка корректности расчётов
- готовая интеграция с CDE
- замена эксперта

## Что нужно от заказчика

1. NDA / соглашение на обезличенный завершённый комплект.
2. IFC + PDF + требования + (по возможности) issue register / заключение.
3. 30-минутное демо + опциональный пилот сравнения количества и критичности замечаний.
4. Закрытый контур; облачный LLM для customer data — только после явного разрешения.

На первом шаге **не** требуем менять СОД.

Черновик; рассылка только после вашего подтверждения.
