# Скрипт звонка

Тон: **ок**. В первом касании не перечислять «чего не обещаем» — только если спросили.

| Что говорю вслух | Что помню про себя |
|---|---|
| «Дмитрий Коньков, команда AeroBIM, программа Техлаб Москва, задача Самолёта.» | Не начинать с архитектуры и тестов. |
| «Не просим отдать комплект. Предлагаем 40 минут у вас: система локально, вы загружаете раздел сами.» | Для экспертизы — только on-prem. Для проектной — можно архив под их NDA. |
| «Сверка модели с чертежами и ТЗ у вас сейчас руками или уже чем-то автоматизируете?» | Слушать. Не перебивать списком функций. |
| «Решение о годности документации остаётся за вашим специалистом — мы собираем совпадения и расхождения с вашим эталоном.» | Единственная «честная» фраза вслух. Не читать список «чего нет». |
| «Цель звонка — слот на 40 минут или имя коллеги, с кем это согласовать.» | Успех = слот или ФИО, не «пришлю презентацию» без уточнения. |
| Если «пришлите»: «Пришлю. Вам важнее, как это встанет в ваш контур, или что именно система находит на эталоне?» | Ответ выбирает one-pager vs сценарий демо. |
| Если «какая точность?»: «На вашем комплекте не знаю — поэтому и предлагаю измерить там, где эталон уже есть.» | Не называть 90%, AECV, бенчмарки. |
| Если «у нас уже есть проверка модели»: «Тогда нам есть о чём поговорить про сверку комплекта: чертёж с моделью, модель с ТЗ, значения с расчётом.» | Не называть конкурентов Техлаба. |

**Приоритет до пятницы:** звонки сегодня–завтра; почта параллельно (DNS не блокер).  
**Не звонить** раньше 10:00 по Москве. После трёх касаний без ответа — стоп навсегда.

**ТРЕБУЕТСЯ ОТ ВЛАДЕЛЬЦА:** кто из двоих звонит (один ответ).
