# AeroBIM pilot one-pager (RU)

**Claims Lock:** продающий текст ≤ инженерных доказательств. Checkpoint **NO_GO**.

## Кто мы

Открытый (MIT) инженерный контур проверки комплектов ПД/РД: IFC, IDS, PDF/drawing evidence, BCF.  
**Проверяет детерминированный движок**; LLM — только advisory-формулировки замечаний. Окончательное решение — у эксперта.

## Проблема

Возвраты экспертизы, коллизии, несогласованность документов, ручная сверка.

## Что просим у заказчика (важно)

Не только демо на действующем объекте. **Архивный завершённый комплект + заключение экспертизы / внутренний реестр замечаний** — это размеченный эталон. Один такой пакет закрывает то, чего нельзя закрыть синтетикой (путь к RT-001).

## Пилот (минимум)

- NDA + обезличенный завершённый комплект **или** архив с заключением
- сравнение: число замечаний + критичность (со mapping шкал)
- AI-only находки **не** считаются ошибкой системы без адъюдикации экспертом (3 категории)
- закрытый контур; данные заказчика не уходят в облако без письменного разрешения (PII-гейт / default deny)

## Что измеряем

precision/recall **только** после адъюдикации на заявленном корпусе; p95 времени; coverage; evidence links.

## Что запрещено обещать

- «точность выше 90%» и любые % точности продукта
- «ИИ проверяет документацию»
- цифры чужого бенчмарка (AECV и т.п.) как точность AeroBIM
- готовность к промышленной эксплуатации / замена эксперта / CDE-ready / универсальный SLA ≤30 мин

## Безопасность

Customer data → облачный LLM только с письменного разрешения. Default deny.
