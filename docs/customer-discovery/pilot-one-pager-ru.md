# AeroBIM pilot one-pager (RU, черновик)

## Кто мы

Инженерный контур проверки комплектов ПД/РД: IFC, IDS, PDF/drawing evidence, BCF export. Детерминированный verdict; LLM — advisory.

## Проблема

Возвраты экспертизы, коллизии, несогласованность документов, ручная сверка.

## Пилот (минимальный объём)

- NDA + обезличенный завершённый комплект
- сравнение: число замечаний + критичность (с mapping)
- 1–2 экспертных adjudicator со стороны заказчика желательны
- без обязательной смены СОД на шаге 1

## Что измеряем

precision/recall только на заявленном корпусе; time-to-first-finding; coverage; review_required.

## Что не обещаем

точность >90%; замена эксперта; любые нормы; нативный DWG; корректность расчётов; CDE-ready; универсальный SLA ≤30 мин.

## Безопасность

Customer data не уходит в облачный LLM без письменного разрешения. Default deny.
