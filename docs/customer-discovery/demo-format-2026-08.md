# Формат демо — каркас

Полный документ с путями A/B (человеческий эталон без корпуса заказчика):  
[`../demo-format-2026-08.md`](../demo-format-2026-08.md).

## Шкала критичности

| Уровень | Определение |
|---|---|
| **Блокирующее** | Препятствует положительному заключению **или** влияет на безопасность |
| **Существенное** | Переделка раздела / повторный цикл согласования |
| **Несущественное** | Оформление / комплектность |

## Правило расхождений

Находка вне заключения ≠ автоматически ошибка системы → эксперт: (1) верная пропущенная · (2) вне области · (3) ложное.
