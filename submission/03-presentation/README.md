Файл деки готовит оператор к 19.08 и прикладывает в форму ссылкой. В git лежит **каркас и дисциплина формулировок**, а не бинарник, — чтобы слайды нельзя было разойтись с реестром заявлений.

| 1 | Проблема | Ручная проверка комплекта: трудозатраты, зависимость от квалификации, человеческая ошибка |
| 2 | Решение | Ассистент приёмки: требование → объект → доказательство. Эксперт остаётся ответственным |

| 4 | Демонстрация | Live CLI: IFC + IDS → находка с GUID, правилом, expected/observed → HTML/JSON/BCF |

| 8 | Дорожная карта | Что закрывает КТ#3 и пилот |
